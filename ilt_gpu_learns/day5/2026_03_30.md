## 📖 核心概念讲解

### 1. CUDA核函数深入

#### 1.1 核函数设计原则

**核函数的黄金法则**:
```
1. 每个线程独立执行，不依赖其他线程的结果
2. 最小化全局内存访问次数
3. 合并内存访问（Coalesced Access）
4. 避免线程分化（Warp Divergence）
```

#### 1.2 内存访问模式

**合并内存访问**（Coalesced Memory Access）:
- 连续的线程访问连续的内存地址
- GPU可以将多个内存访问合并成一次事务
- 性能提升可达10-100倍

**生活类比**:
想象你在图书馆借书：
- **合并访问**：每个人借相邻的书架上的书，图书管理员可以一次性取完
- **非合并访问**：每个人借随机分散的书，图书管理员需要跑很多次

```cuda
// ❌ 错误示例：非合并访问
__global__ void badAccess(float* data, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    // 跨步访问，每个线程访问间隔很大的地址
    int bad_idx = idx * 32;  // 跨步32
    if (bad_idx < n) {
        data[bad_idx] = idx;
    }
}

// ✅ 正确示例：合并访问
__global__ void goodAccess(float* data, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    // 连续线程访问连续地址
    if (idx < n) {
        data[idx] = idx;
    }
}
```

#### 1.3 共享内存（Shared Memory）

**共享内存的优势**:
- 延迟极低：约20个时钟周期（全局内存需要400个周期）
- 带宽极高：约几TB/s
- 可被线程块内所有线程共享

**生活类比**:
想象一个工作小组：
- **全局内存**：公共仓库，取货慢，距离远
- **共享内存**：小组的工作台，取货快，就在手边

```cuda
// 使用共享内存的矩阵乘法示例
__global__ void matrixMulShared(float* A, float* B, float* C, 
                                  int width) {
    // 1. 定义共享内存（每个线程块共享）
    __shared__ float As[TILE_SIZE][TILE_SIZE];
    __shared__ float Bs[TILE_SIZE][TILE_SIZE];
    
    // 2. 计算线程索引
    int bx = blockIdx.x;  int by = blockIdx.y;
    int tx = threadIdx.x; int ty = threadIdx.y;
    int row = by * TILE_SIZE + ty;
    int col = bx * TILE_SIZE + tx;
    
    float value = 0.0f;
    
    // 3. 分块计算
    for (int m = 0; m < width / TILE_SIZE; ++m) {
        // 4. 协作加载到共享内存
        As[ty][tx] = A[row * width + m * TILE_SIZE + tx];
        Bs[ty][tx] = B[(m * TILE_SIZE + ty) * width + col];
        
        // 5. 同步，确保所有数据都加载完成
        __syncthreads();
        
        // 6. 计算当前块的贡献
        for (int k = 0; k < TILE_SIZE; ++k) {
            value += As[ty][k] * Bs[k][tx];
        }
        
        // 7. 再次同步，确保计算完成
        __syncthreads();
    }
    
    // 8. 写回结果
    C[row * width + col] = value;
}
```

#### 1.4 线程同步

**`__syncthreads()`的作用**:
- 线程块内所有线程在此处等待
- 确保所有线程都执行到这一点
- 常用于共享内存的读写同步

**重要规则**:
```cuda
// ✅ 正确：所有线程都执行同步
if (condition) {
    __shared__ float data[256];
    data[idx] = value;
    __syncthreads();  // 块内所有线程都执行
}

// ❌ 错误：线程分化导致死锁
if (idx < 128) {
    __syncthreads();  // 只有部分线程执行 → 死锁！
}
```

#### 1.5 原子操作

**原子操作的应用场景**:
- 多个线程需要更新同一个变量
- 避免竞争条件（Race Condition）

**生活类比**:
想象多个人同时修改一份文档：
- **无原子操作**：多人同时修改，可能互相覆盖
- **原子操作**：一次只能一个人修改，其他人等待

```cuda
// 原子加法示例
__global__ void atomicAddDemo(int* counter, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < n) {
        // 原子加法，确保线程安全
        atomicAdd(counter, 1);
    }
}

// 常用的原子操作
atomicAdd(&data[idx], value);      // 原子加法
atomicSub(&data[idx], value);      // 原子减法
atomicExch(&data[idx], value);     // 原子交换
atomicMin(&data[idx], value);      // 原子最小值
atomicMax(&data[idx], value);      // 原子最大值
atomicCAS(&data[idx], comp, val);  // 原子比较并交换
```

### 2. 性能优化技巧

#### 2.1 内存优化策略

**策略1: 使用共享内存缓存数据**
- 将频繁访问的全局内存数据缓存到共享内存
- 适用于数据重用场景

**策略2: 内存访问对齐**
- 确保数据在内存中对齐存储
- 使用 `__align__(16)` 或 `cudaMallocPitch`

**策略3: 向量化内存访问**
- 使用 `float4`、`int4` 等向量类型
- 一次访问128字节，提高带宽利用率

```cuda
// 向量化内存访问示例
__global__ void vectorAccess(float4* data, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < n) {
        float4 val = data[idx];  // 一次读取4个float
        // 处理 val.x, val.y, val.z, val.w
    }
}
```

#### 2.2 计算优化策略

**策略1: 减少寄存器压力**
- 避免过多局部变量
- 重用变量减少寄存器占用

**策略2: 循环展开**
- 手动或使用 `#pragma unroll` 展开
- 减少循环开销

```cuda
// 循环展开示例
__global__ void loopUnroll(float* data, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    
    // 手动展开
    #pragma unroll 4
    for (int i = 0; i < n; i += 4) {
        data[idx + i] += 1.0f;
    }
}
```

**策略3: 避免线程分化**
- 减少条件分支
- 使用条件表达式替代if-else

```cuda
// ❌ 线程分化示例
__global__ void divergence(int* data, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < n / 2) {
        data[idx] = 0;  // 前一半线程执行
    } else {
        data[idx] = 1;  // 后一半线程执行
    }
}

// ✅ 优化示例
__global__ void noDivergence(int* data, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    // 使用条件表达式，减少分化
    data[idx] = (idx < n / 2) ? 0 : 1;
}
```

#### 2.3 占用率优化

**占用率（Occupancy）**:
- 活跃线程束数量 / 最大线程束数量
- 理想值：接近100%
- 工具：CUDA Occupancy Calculator

**影响占用率的因素**:
1. 每个线程块的线程数量
2. 每个线程的寄存器数量
3. 每个线程块的共享内存数量

```cuda
// 查询设备属性
cudaDeviceProp prop;
cudaGetDeviceProperties(&prop, 0);

printf("最大线程块大小: %d\n", prop.maxThreadsPerBlock);
printf("最大线程块维度: %d x %d x %d\n", 
       prop.maxThreadsDim[0], prop.maxThreadsDim[1], prop.maxThreadsDim[2]);
printf("每个SM最大线程数: %d\n", prop.maxThreadsPerMultiProcessor);
```

### 3. GPU加速数学运算

#### 3.1 向量运算优化

**向量加法**（基础优化）:
```cuda
__global__ void vectorAdd(float* a, float* b, float* c, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < n) {
        c[idx] = a[idx] + b[idx];
    }
}

// 优化版本：向量化访问
__global__ void vectorAddOptimized(float4* a, float4* b, float4* c, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < n) {
        float4 va = a[idx];
        float4 vb = b[idx];
        float4 vc;
        vc.x = va.x + vb.x;
        vc.y = va.y + vb.y;
        vc.z = va.z + vb.z;
        vc.w = va.w + vb.w;
        c[idx] = vc;
    }
}
```

#### 3.2 矩阵运算优化

**矩阵转置**（使用共享内存）:
```cuda
#define TILE_SIZE 32

__global__ void matrixTranspose(float* input, float* output, 
                                  int width, int height) {
    __shared__ float tile[TILE_SIZE][TILE_SIZE + 1];  // 避免bank冲突
    
    int x = blockIdx.x * TILE_SIZE + threadIdx.x;
    int y = blockIdx.y * TILE_SIZE + threadIdx.y;
    
    // 从全局内存读取到共享内存
    if (x < width && y < height) {
        tile[threadIdx.y][threadIdx.x] = input[y * width + x];
    }
    __syncthreads();
    
    // 从共享内存写入到全局内存（转置）
    x = blockIdx.y * TILE_SIZE + threadIdx.x;
    y = blockIdx.x * TILE_SIZE + threadIdx.y;
    if (x < height && y < width) {
        output[y * height + x] = tile[threadIdx.x][threadIdx.y];
    }
}
```

#### 3.3 归约运算

**向量求和**（优化归约）:
```cuda
__global__ void reduceSum(float* input, float* output, int n) {
    __shared__ float sdata[256];
    
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    int tid = threadIdx.x;
    
    // 加载数据到共享内存
    sdata[tid] = (idx < n) ? input[idx] : 0.0f;
    __syncthreads();
    
    // 树形归约
    for (int s = blockDim.x / 2; s > 0; s >>= 1) {
        if (tid < s) {
            sdata[tid] += sdata[tid + s];
        }
        __syncthreads();
    }
    
    // 只有第一个线程写入结果
    if (tid == 0) {
        output[blockIdx.x] = sdata[0];
    }
}
```

## 📊 性能优化总结

### 优化技巧速查表

| 优化技术 | 性能提升 | 适用场景 |
|---------|---------|---------|
| **合并内存访问** | 10-100倍 | 所有全局内存访问 |
| **共享内存缓存** | 2-10倍 | 数据重用场景 |
| **向量化访问** | 2-4倍 | 连续数据处理 |
| **循环展开** | 1.5-2倍 | 循环密集型计算 |
| **避免线程分化** | 2-3倍 | 条件分支较多 |
| **原子操作** | 线程安全 | 多线程更新同一变量 |

### 性能分析流程

```
1. 使用 nvprof 找到性能瓶颈
   nvprof --print-gpu-trace ./program

2. 分析内存访问模式
   nvprof --metrics gld_efficiency,gst_efficiency ./program

3. 分析计算吞吐量
   nvprof --metrics flops_sp,achieved_occupancy ./program

4. 优化瓶颈，重新测试
```
