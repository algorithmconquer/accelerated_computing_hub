#### 1.1 矩阵:图像的数学表示

**简单理解**: 矩阵就是一个数字表格,图像在计算机中就是用矩阵表示的。

#### 1.3 特征值与特征向量

**简单理解**: 特征值和特征向量描述了矩阵的"内在特性"。

**生活类比**:
想象你拉伸一块橡皮泥:
- 某些方向拉伸得特别多(大特征值)
- 某些方向几乎不变(小特征值)
- 这些方向就是特征向量

**在光刻中的应用**:
- 分析光学系统的特性
- 理解图像的主要变化方向
- SOCS(Source Optimization Coherent Systems)方法使用特征值分解

```python
import torch
import numpy as np

# 创建一个对称矩阵(代表光学传输函数)
A = torch.tensor([
    [4.0, 1.0, 1.0],
    [1.0, 3.0, 0.5],
    [1.0, 0.5, 2.0]
], device='cuda')

print("原始矩阵 A:")
print(A)

# 计算特征值和特征向量
eigenvalues, eigenvectors = torch.linalg.eigh(A)  # 对称矩阵用eigh

print("\n特征值(从小到大):")
print(eigenvalues)

print("\n特征向量(每列对应一个特征值):")
print(eigenvectors)

# 验证: A * v = λ * v
print("\n验证特征值方程 A * v = λ * v:")
for i in range(len(eigenvalues)):
    v = eigenvectors[:, i]
    lambda_val = eigenvalues[i]
    Av = torch.matmul(A, v)
    lambda_v = lambda_val * v
    error = torch.norm(Av - lambda_v)
    print(f"特征值 {i+1}: λ={lambda_val:.4f}, 误差={error:.6f}")

# 物理意义:特征值表示不同"模式"的强度
print("\n物理意义解释:")
print(f"- 最大特征值 {eigenvalues[-1]:.4f}: 主导模式,影响最大")
print(f"- 最小特征值 {eigenvalues[0]:.4f}: 微弱模式,影响最小")
print("- 在SOCS方法中,我们只保留大的特征值对应的光源模式")
```

### 2. 傅里叶变换:频域分析的核心

#### 2.1 什么是傅里叶变换?

**简单理解**: 傅里叶变换将信号从"时间/空间域"转换到"频率域"。

**生活类比**:
- 想象你在听一首音乐,时间域就是音符按时间播放,频率域就是看到这首曲子用了哪些音符(C调、G调等)
- 就像把一道菜分解成各种配料:原本是混合在一起的味道,分解后能看到每种配料的成分

**为什么在光刻中需要傅里叶变换?**
- 光波是波动现象,具有频率特性
- 光学系统的成像过程是卷积运算,在频域变为乘法(更简单)
- 衍射现象用傅里叶变换描述最自然

#### 2.2 一维傅里叶变换示例

```python
import torch
import numpy as np
import matplotlib.pyplot as plt

# 创建一个复合信号(两个不同频率的正弦波)
fs = 1000  # 采样频率
t = torch.linspace(0, 1, fs, device='cuda')  # 1秒,1000个采样点

# 信号 = 50Hz正弦波 + 120Hz正弦波
f1, f2 = 50, 120  # 两个频率分量
signal = torch.sin(2 * np.pi * f1 * t) + 0.5 * torch.sin(2 * np.pi * f2 * t)

print("原始信号:")
print(f"- 采样点数: {len(signal)}")
print(f"- 信号形状: {signal.shape}")
print(f"- 设备: {signal.device}")

# 应用快速傅里叶变换(FFT)
signal_fft = torch.fft.fft(signal)

# 计算频率轴
freqs = torch.fft.fftfreq(fs, 1/fs, device='cuda')

# 计算幅度谱(只取正频率部分)
magnitude = torch.abs(signal_fft)
magnitude_db = 20 * torch.log10(magnitude + 1e-10)  # 转换为分贝

# 可视化
fig, axes = plt.subplots(2, 1, figsize=(12, 8))

# 时间域信号
axes[0].plot(t[:100].cpu(), signal[:100].cpu())
axes[0].set_xlabel('时间 (秒)')

axes[0].set_title('时间域信号(前100个采样点)')
axes[0].grid(True, alpha=0.3)

# 频率域信号
positive_freq_mask = freqs > 0
axes[1].plot(freqs[positive_freq_mask].cpu(), magnitude[positive_freq_mask].cpu())
axes[1].set_xlabel('频率 (Hz)')
axes[1].set_ylabel('幅度')
axes[1].set_title('频率域信号(幅度谱)')
axes[1].set_xlim(0, 200)
axes[1].grid(True, alpha=0.3)

# 标记峰值
axes[1].axvline(x=f1, color='r', linestyle='--', alpha=0.5, label=f'{f1}Hz')
axes[1].axvline(x=f2, color='g', linestyle='--', alpha=0.5, label=f'{f2}Hz')
axes[1].legend()

plt.tight_layout()
plt.savefig('fft_1d_example.png', dpi=150, bbox_inches='tight')
print("\n傅里叶变换可视化已保存为 fft_1d_example.png")

print("\n频率域分析:")
print(f"- 在 {f1}Hz 处有明显峰值")
print(f"- 在 {f2}Hz 处有较小峰值(幅度约为前者的0.5倍)")
print(f"- 这正确反映了原始信号的组成!")
```

#### 2.4 卷积定理:频域卷积

**重要定理**: 
- 空间域的卷积 = 频域的乘法
- 这使得卷积运算大大加速!

```python
import torch
import time

# 创建大图像和卷积核
image_size = 2048
kernel_size = 15

# 创建测试图像(随机图案)
image = torch.randn(image_size, image_size, device='cuda')

# 创建高斯卷积核
x = torch.arange(kernel_size, device='cuda') - kernel_size // 2
gaussian_1d = torch.exp(-x**2 / (2 * 5.0**2))
gaussian_2d = gaussian_1d.unsqueeze(0) * gaussian_1d.unsqueeze(1)
gaussian_2d /= gaussian_2d.sum()  # 归一化

print("测试卷积定理:")
print(f"- 图像大小: {image_size}x{image_size}")
print(f"- 卷积核大小: {kernel_size}x{kernel_size}")

# 方法1:空间域卷积(使用conv2d)
from torch.nn.functional import conv2d

start = time.time()
# 需要添加批次和通道维度
image_4d = image.unsqueeze(0).unsqueeze(0)
kernel_4d = gaussian_2d.unsqueeze(0).unsqueeze(0)
result_spatial = conv2d(image_4d, kernel_4d, padding=kernel_size//2)
torch.cuda.synchronize()
time_spatial = time.time() - start

print(f"\n空间域卷积时间: {time_spatial:.4f}秒")

# 方法2:频域卷积
start = time.time()

# 计算填充后的大小(避免循环卷积效应)
padded_size = image_size + kernel_size - 1

# 填充图像和核
image_padded = torch.zeros(padded_size, padded_size, device='cuda')
image_padded[:image_size, :image_size] = image

kernel_padded = torch.zeros(padded_size, padded_size, device='cuda')
kernel_padded[:kernel_size, :kernel_size] = gaussian_2d

# FFT
image_fft = torch.fft.fft2(image_padded)
kernel_fft = torch.fft.fft2(kernel_padded)

# 频域相乘
result_fft = image_fft * kernel_fft

# 逆FFT
result_frequency_full = torch.fft.ifft2(result_fft).real

# 提取有效区域
result_frequency = result_frequency_full[kernel_size//2:kernel_size//2+image_size, 
                                          kernel_size//2:kernel_size//2+image_size]

torch.cuda.synchronize()
time_frequency = time.time() - start

print(f"频域卷积时间: {time_frequency:.4f}秒")

# 比较结果(应该相同)
difference = torch.abs(result_spatial.squeeze() - result_frequency).max()
print(f"\n两种方法的最大差异: {difference:.6f}")
print("(差异应接近0,验证卷积定理)")

# 对于大核,频域卷积更快
if kernel_size > 15:
    speedup = time_spatial / time_frequency
    print(f"\n加速比: {speedup:.2f}x")
    print("结论:对于大卷积核,频域方法更快")
else:
    print("\n结论:对于小卷积核,空间域方法通常更快")
    print("(但频域方法在理论分析中很重要)")
```

**输出示例**:
```

- 图像大小: 2048x2048
- 卷积核大小: 15x15

空间域卷积时间: 0.0234秒

两种方法的最大差异: 0.000001
```

### 3. 优化算法基础

#### 3.1 什么是优化?

**简单理解**: 优化就是找到让目标函数最大或最小的参数值。

**生活类比**:
- 登山:找到最高峰(最大化)或最低谷(最小化)
- 购物:在预算约束下买到最满意的东西
- 导航:找到最短路径

**在光刻中的应用**:
- ILT核心就是优化问题:找到最优掩模图案
- 目标:使晶圆图案尽可能接近目标图案
- 约束:掩模可制造性、工艺窗口等

#### 3.2 梯度下降法

**核心思想**: 沿着梯度的反方向移动,逐步接近最小值。

**数学表达**:
```
x_{n+1} = x_n - α * ∇f(x_n)
```
其中:
- `x`: 参数
- `α`: 学习率(步长)
- `∇f`: 梯度(导数)

**生活类比**:
想象你在山上蒙着眼睛想下山:
1. 用脚试探周围的坡度(计算梯度)
2. 向下坡最陡的方向走一步
3. 重复直到到达山谷

```python
import torch
import numpy as np
import matplotlib.pyplot as plt

# 定义一个简单的优化目标函数
# Rosenbrock函数(经典的优化测试函数)
def rosenbrock(x, y):
    """Rosenbrock函数: f(x,y) = (a-x)^2 + b(y-x^2)^2"""
    a, b = 1.0, 100.0
    return (a - x)**2 + b * (y - x**2)**2

# 创建搜索空间
x_range = np.linspace(-2, 2, 100)
y_range = np.linspace(-1, 3, 100)
X, Y = np.meshgrid(x_range, y_range)
Z = rosenbrock(X, Y)

print("Rosenbrock函数优化:")
print("- 这是一个经典的优化测试函数")
print("- 全局最小值在 (1, 1)")
print("- 函数值在该点为 0")

# 可视化函数曲面
fig = plt.figure(figsize=(15, 5))

# 3D曲面
ax1 = fig.add_subplot(131, projection='3d')
ax1.plot_surface(X, Y, np.log(Z + 1), cmap='viridis', alpha=0.8)
ax1.set_xlabel('x')
ax1.set_ylabel('y')
ax1.set_zlabel('log(f(x,y))')
ax1.set_title('Rosenbrock函数(对数尺度)')

# 等高线
ax2 = fig.add_subplot(132)
contour = ax2.contour(X, Y, Z, levels=np.logspace(-1, 3, 20), cmap='viridis')
ax2.set_xlabel('x')
ax2.set_ylabel('y')
ax2.set_title('等高线图')
plt.colorbar(contour, ax=ax2, label='函数值')

# 优化路径
ax3 = fig.add_subplot(133)
ax3.contour(X, Y, Z, levels=np.logspace(-1, 3, 20), cmap='viridis', alpha=0.3)

# 使用PyTorch进行梯度下降优化
x = torch.tensor([-1.5], requires_grad=True, device='cuda')
y = torch.tensor([2.5], requires_grad=True, device='cuda')

# 记录优化路径
path_x = [x.item()]
path_y = [y.item()]
losses = [rosenbrock(x.item(), y.item())]

# 梯度下降
learning_rate = 0.002
iterations = 2000

for i in range(iterations):
    # 计算损失
    loss = rosenbrock(x, y)
    
    # 反向传播
    loss.backward()
    
    # 更新参数
    with torch.no_grad():
        x -= learning_rate * x.grad
        y -= learning_rate * y.grad
        
        # 清零梯度
        x.grad.zero_()
        y.grad.zero_()
    
    # 记录
    path_x.append(x.item())
    path_y.append(y.item())
    losses.append(loss.item())
    
    if i % 500 == 0:
        print(f"迭代 {i:4d}: x={x.item():.4f}, y={y.item():.4f}, loss={loss.item():.6f}")

# 绘制优化路径
ax3.plot(path_x, path_y, 'r.-', linewidth=1, markersize=3, label='优化路径')
ax3.plot(path_x[0], path_y[0], 'go', markersize=10, label='起点')
ax3.plot(1, 1, 'r*', markersize=15, label='最优解(1,1)')
ax3.set_xlabel('x')
ax3.set_ylabel('y')

ax3.legend()
ax3.grid(True, alpha=0.3)

plt.tight_layout()
```

#### 3.3 优化算法比较

```python
import torch
import numpy as np
import matplotlib.pyplot as plt

# 定义优化目标:二次函数
def quadratic(x):
    """简单的二次函数: f(x) = x^2"""
    return x ** 2

# 不同优化算法的实现
def gradient_descent(x_init, lr, iterations):
    """标准梯度下降"""
    x = torch.tensor([x_init], requires_grad=True, device='cuda')
    path = [x.item()]
    
    for _ in range(iterations):
        loss = quadratic(x)
        loss.backward()
        with torch.no_grad():
            x -= lr * x.grad
            x.grad.zero_()
        path.append(x.item())
    
    return path

def momentum(x_init, lr, momentum_coeff, iterations):
    """带动量的梯度下降"""
    x = torch.tensor([x_init], requires_grad=True, device='cuda')
    velocity = torch.tensor([0.0], device='cuda')
    path = [x.item()]
    
    for _ in range(iterations):
        loss = quadratic(x)
        loss.backward()
        
        with torch.no_grad():
            velocity = momentum_coeff * velocity + lr * x.grad
            x -= velocity
            x.grad.zero_()
        path.append(x.item())
    
    return path

def adam(x_init, lr, iterations):
    """Adam优化器"""
    x = torch.tensor([x_init], requires_grad=True, device='cuda')
    optimizer = torch.optim.Adam([x], lr=lr)
    path = [x.item()]
    
    for _ in range(iterations):
        optimizer.zero_grad()
        loss = quadratic(x)
        loss.backward()
        optimizer.step()
        path.append(x.item())
    
    return path

# 测试不同算法

iterations = 50
lr = 0.1

path_adam = adam(x_init, lr, iterations)

# 可视化

# 优化路径

y_range = x_range ** 2

axes[0].plot(x_range, y_range, 'b-', label='f(x) = x²', alpha=0.5)
axes[0].plot(path_gd, [x**2 for x in path_gd], 'r.-', label='梯度下降', markersize=4)
axes[0].plot(path_momentum, [x**2 for x in path_momentum], 'g.-', label='动量法', markersize=4)
axes[0].plot(path_adam, [x**2 for x in path_adam], 'm.-', label='Adam', markersize=4)
```

```python
import numpy as np

import time

for size in sizes:
    print(f"测试矩阵大小: {size}x{size}")
    
    # NumPy (CPU)
    a_np = np.random.randn(size, size).astype(np.float32)
    b_np = np.random.randn(size, size).astype(np.float32)
    
    start = time.time()
    c_np = np.matmul(a_np, b_np)
    time_numpy = time.time() - start
    
    # PyTorch CPU
    a_torch_cpu = torch.from_numpy(a_np)
    b_torch_cpu = torch.from_numpy(b_np)
    
    start = time.time()
    c_torch_cpu = torch.matmul(a_torch_cpu, b_torch_cpu)
    time_torch_cpu = time.time() - start
    
    # PyTorch GPU
    a_torch_gpu = a_torch_cpu.cuda()
    b_torch_gpu = b_torch_cpu.cuda()
    
    # 预热
    _ = torch.matmul(a_torch_gpu, b_torch_gpu)
    torch.cuda.synchronize()
    
    start = time.time()
    c_torch_gpu = torch.matmul(a_torch_gpu, b_torch_gpu)
    torch.cuda.synchronize()
    time_torch_gpu = time.time() - start
```
